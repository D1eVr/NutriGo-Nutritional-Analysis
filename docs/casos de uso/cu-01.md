# CU-01 · Crear una cuenta

| Campo | Contenido |
|---|---|
| **Actor principal** | Paciente |
| **Objetivo** | Crear su cuenta en NutriGo! para empezar a llevar el seguimiento de su alimentación y de sus cambios físicos. |
| **Precondición** | La persona tiene la aplicación instalada en su teléfono y un correo electrónico. |
| **Escenario principal** | 1. La persona abre la aplicación y elige "Crear cuenta".<br>2. El sistema pide nombre, correo electrónico, contraseña, fecha de nacimiento, sexo y estatura.<br>3. La persona llena los datos y confirma.<br>4. El sistema verifica que el correo no esté registrado y que todos los datos estén completos.<br>5. El sistema crea la cuenta y muestra la pantalla de inicio del paciente. |
| **Flujos alternos** | 4a. El correo ya está registrado: el sistema no crea la cuenta, avisa y ofrece iniciar sesión.<br>4b. Falta algún dato o la estatura está fuera del rango permitido: el sistema señala el campo y la persona lo corrige antes de continuar. |
| **Postcondición** | La cuenta existe y el paciente queda con la sesión iniciada, todavía sin registros ni preferencias alimenticias. |
| **Requisitos que realiza** | RF-001, RNF-CON-002 |
