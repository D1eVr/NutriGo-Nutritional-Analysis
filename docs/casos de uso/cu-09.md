# CU-09 · Consultar el progreso físico

| Campo | Contenido |
|---|---|
| **Actor principal** | Paciente |
| **Objetivo** | Conocer cómo han cambiado su peso, su IMC y su composición corporal. |
| **Precondición** | El paciente tiene la sesión iniciada. |
| **Escenario principal** | 1. El paciente abre la sección "Progreso" desde la pantalla de inicio.<br>2. El sistema muestra el peso, el IMC, el porcentaje de grasa y el porcentaje de músculo más recientes.<br>3. El paciente elige un indicador y un periodo: última semana, último mes o último año.<br>4. El sistema muestra la gráfica con la evolución del indicador en ese periodo. |
| **Flujos alternos** | 2a. No existe ninguna medición de grasa o de músculo: esos indicadores aparecen como "Sin medición".<br>3a. El paciente elige el último año: la gráfica muestra un punto por mes tomado del resumen mensual.<br>4a. Hay días sin registro en el periodo: la gráfica deja el hueco y no lo rellena con ningún valor. |
| **Postcondición** | El paciente conoce su progreso con base solo en los datos que realmente registró. |
| **Requisitos que realiza** | RF-014, RNF-USA-002, RNF-CON-001 |
