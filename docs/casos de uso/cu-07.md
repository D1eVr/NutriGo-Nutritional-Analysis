# CU-07 · Registrar el seguimiento diario

| Campo | Contenido |
|---|---|
| **Actor principal** | Paciente |
| **Objetivo** | Registrar los datos del día para que su progreso y su siguiente plan alimenticio se calculen con información real. |
| **Precondición** | El paciente tiene la sesión iniciada y su estatura registrada. Si tiene un dispositivo, ya está vinculado. |
| **Escenario principal** | 1. El paciente abre el registro del día desde la pantalla de inicio.<br>2. El sistema muestra los datos del día e indica cuáles ya llegaron del dispositivo y cuáles faltan.<br>3. El paciente revisa los datos que llegaron del dispositivo.<br>4. El paciente captura los datos que faltan, como el agua y los alimentos de cada comida.<br>5. El sistema verifica que cada valor esté dentro del rango permitido.<br>6. El paciente confirma el registro.<br>7. El sistema guarda el registro del día y actualiza sus indicadores.<br>8. El sistema muestra el día como "Completo" en la pantalla de inicio. |
| **Flujos alternos** | 1a. Hay días anteriores sin registro: el sistema muestra cuántos días quedaron sin registro, pero deja continuar con el día actual. Esos días quedan como "Sin registro" y el caso continúa en el paso 2.<br>2a. El dispositivo no envió algún dato: el sistema marca el dato como "Sin dato del dispositivo" y habilita su captura manual. El paciente lo captura y el caso continúa en el paso 5.<br>3a. Un dato del dispositivo es incorrecto: el paciente corrige el valor y el sistema guarda la corrección. El caso continúa en el paso 4.<br>5a. Un valor está fuera de rango: el sistema no acepta el valor, señala el campo y muestra el rango permitido. El paciente lo corrige y el caso regresa al paso 5.<br>6a. El paciente no captura todos los datos: el sistema guarda los datos capturados, marca los demás como "Sin registro" y muestra el día como "Incompleto". El caso termina. |
| **Postcondición** | El registro del día queda guardado. Los datos que no se capturaron quedan como "Sin registro" y no se reemplazan por valores estimados. |
| **Requisitos que realiza** | RF-007, RF-008, RF-009, RF-012, RNF-USA-001, RNF-CON-001, RNF-CON-002 |
