# CU-04 · Actualizar los datos personales

| Campo | Contenido |
|---|---|
| **Actor principal** | Paciente |
| **Objetivo** | Mantener correctos sus datos personales para que su IMC y su plan se calculen bien. |
| **Precondición** | El paciente tiene la sesión iniciada. |
| **Escenario principal** | 1. El paciente abre su perfil y elige "Datos personales".<br>2. El sistema muestra su nombre, fecha de nacimiento, estatura en centímetros y sexo.<br>3. El paciente modifica el dato que necesita cambiar y elige "Guardar cambios".<br>4. El sistema verifica que los datos estén completos y dentro del rango permitido.<br>5. El sistema guarda el cambio y lo muestra en sus datos personales.<br>6. El sistema usa los datos actualizados en los siguientes cálculos del IMC y en el siguiente plan alimenticio. |
| **Flujos alternos** | **3a. El paciente sale sin guardar (RF-006):**<br>3a1. El sistema descarta los cambios y conserva los datos anteriores.<br>3a2. El caso regresa al paso 1, con el paciente en su perfil.<br><br>**4a. El paciente dejó un dato vacío (RF-006):**<br>4a1. El sistema no guarda el cambio y señala el campo vacío.<br>4a2. El paciente llena el dato y elige "Guardar cambios".<br>4a3. El caso regresa al paso 4.<br><br>**4b. La estatura está fuera del rango de 50 a 250 cm (RNF-CON-002):**<br>4b1. El sistema no guarda el cambio, señala el campo y muestra el rango permitido.<br>4b2. El paciente corrige la estatura y elige "Guardar cambios".<br>4b3. El caso regresa al paso 4. |
| **Postcondición** | Los datos personales quedan actualizados y los siguientes cálculos de IMC usan la nueva estatura. |
| **Requisitos que realiza** | RF-006, RNF-CON-002 |
| **Pantallas del prototipo** | P07 Perfil, P07-A Datos personales |
