# CU-04 · Actualizar los datos personales

| Campo | Contenido |
|---|---|
| **Actor principal** | Paciente |
| **Objetivo** | Mantener correctos sus datos personales para que su IMC y su plan se calculen bien. |
| **Precondición** | El paciente tiene la sesión iniciada. |
| **Escenario principal** | 1. El paciente abre su perfil.<br>2. El sistema muestra su nombre, fecha de nacimiento, sexo y estatura.<br>3. El paciente modifica el dato que necesita cambiar y guarda.<br>4. El sistema verifica que el valor esté dentro del rango permitido.<br>5. El sistema guarda el cambio y lo muestra en el perfil. |
| **Flujos alternos** | 3a. El paciente sale sin guardar: el sistema conserva los datos anteriores.<br>4a. El valor está fuera del rango permitido: el sistema no lo guarda, señala el campo y muestra el rango; el paciente lo corrige. |
| **Postcondición** | Los datos personales quedan actualizados y los siguientes cálculos de IMC usan la nueva estatura. |
| **Requisitos que realiza** | RF-006, RNF-CON-002 |
