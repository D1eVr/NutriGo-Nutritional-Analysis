# CU-08 · Corregir un registro

| Campo | Contenido |
|---|---|
| **Actor principal** | Paciente |
| **Objetivo** | Corregir un dato equivocado para que su progreso no muestre información incorrecta. |
| **Precondición** | El paciente tiene la sesión iniciada y existe un registro dentro de los últimos 30 días. |
| **Escenario principal** | 1. El paciente abre su historial de registros.<br>2. El paciente elige el día que quiere corregir.<br>3. El sistema muestra los datos registrados ese día.<br>4. El paciente elige el dato y captura el valor correcto.<br>5. El sistema verifica que el valor esté dentro del rango permitido.<br>6. El sistema reemplaza el dato y, si es el peso, vuelve a calcular el IMC de ese día. |
| **Flujos alternos** | 2a. El día tiene más de 30 días: sus registros ya están en el resumen mensual y el sistema indica que no se pueden corregir.<br>5a. El valor está fuera de rango: el sistema no lo acepta, muestra el rango permitido y el paciente lo corrige. |
| **Postcondición** | El registro del día muestra el valor corregido y los indicadores se calculan con él. |
| **Requisitos que realiza** | RF-010, RNF-CON-002 |
