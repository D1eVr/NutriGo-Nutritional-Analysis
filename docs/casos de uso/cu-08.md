# CU-08 · Corregir un registro

| Campo | Contenido |
|---|---|
| **Actor principal** | Paciente |
| **Objetivo** | Corregir un dato equivocado para que su progreso no muestre información incorrecta. |
| **Precondición** | El paciente tiene la sesión iniciada y existe un registro dentro de los últimos 30 días. |
| **Escenario principal** | 1. El paciente abre el registro del día y elige "Corregir un dato".<br>2. El sistema muestra los datos registrados ese día con su valor y su origen: báscula, reloj o captura manual.<br>3. El paciente elige el dato que quiere corregir.<br>4. El paciente captura el valor correcto y elige "Guardar corrección".<br>5. El sistema verifica que el valor esté dentro del rango permitido.<br>6. El sistema reemplaza el dato y vuelve a calcular los indicadores que dependen de él, como el IMC cuando se corrige el peso.<br>7. El sistema muestra el registro del día con el valor corregido. |
| **Flujos alternos** | **1a. El dato que quiere corregir es de un día anterior (RF-010):**<br>1a1. El paciente abre su historial y elige el día.<br>1a2. El caso continúa en el paso 2 con los datos de ese día.<br><br>**1b. El día elegido tiene más de 30 días de antigüedad (RF-027):**<br>1b1. El sistema indica que los registros de ese mes ya forman parte del resumen mensual y no se pueden corregir.<br>1b2. Si el paciente elige un día de los últimos 30 días, el caso continúa en el paso 2.<br>1b3. Si no, el caso termina sin cambios, porque el resumen mensual no se modifica.<br><br>**5a. El valor está fuera de rango (RNF-CON-002):**<br>5a1. El sistema no acepta el valor y muestra el rango permitido.<br>5a2. El paciente captura un valor dentro del rango.<br>5a3. El caso regresa al paso 5.<br><br>**6a. El dispositivo vuelve a sincronizar ese dato después de la corrección (RF-010):**<br>6a1. El sistema conserva el valor corregido y no lo sobrescribe con el valor del dispositivo.<br>6a2. El caso continúa en el paso 7. |
| **Postcondición** | El registro del día muestra el valor corregido y los indicadores se calculan con él. |
| **Requisitos que realiza** | RF-010, RF-027, RNF-CON-002 |
| **Relaciones** | «extend» hacia CU-07 Registrar el seguimiento diario, en el punto de extensión "dato incorrecto" (flujo 3a de CU-07). También puede iniciarse desde el historial (flujo 1a). |
| **Pantallas del prototipo** | P03 Registro del día, P03-A Corregir un dato |
