# CU-10 · Descargar un informe

| Campo | Contenido |
|---|---|
| **Actor principal** | Paciente |
| **Objetivo** | Obtener en PDF sus avances y su plan de una semana o de un mes para guardarlos o mostrárselos a su nutriólogo. |
| **Precondición** | El paciente tiene la sesión iniciada. |
| **Escenario principal** | 1. El paciente abre la sección "Progreso" y elige "Informes".<br>2. El sistema pregunta si quiere un informe semanal o mensual.<br>3. El paciente elige el tipo de informe y el periodo.<br>4. El sistema genera el PDF con los avances y el plan alimenticio de ese periodo.<br>5. El paciente descarga el informe. |
| **Flujos alternos** | 3a. El periodo elegido tiene más de 30 días de antigüedad: el sistema entrega el resumen mensual de ese mes.<br>3b. El periodo no tiene ningún registro: el sistema avisa que no hay información para ese periodo.<br>4a. Hay días sin registro en el periodo: el informe los muestra como "Sin registro". |
| **Postcondición** | El paciente tiene el PDF de sus avances y su plan del periodo elegido. |
| **Requisitos que realiza** | RF-026, RF-027, RNF-CON-001 |
