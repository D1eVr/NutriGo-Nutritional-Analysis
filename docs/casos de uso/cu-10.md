# CU-10 · Descargar un informe

| Campo | Contenido |
|---|---|
| **Actor principal** | Paciente |
| **Objetivo** | Obtener en PDF sus avances y su plan de una semana o de un mes para guardarlos o mostrárselos a su nutriólogo. |
| **Precondición** | El paciente tiene la sesión iniciada. |
| **Escenario principal** | 1. El paciente abre "Mi progreso" y elige "Descargar informe".<br>2. El sistema pide elegir el tipo de informe: semanal o mensual.<br>3. El paciente elige el tipo de informe.<br>4. El sistema muestra los periodos disponibles con el número de días con registro de cada uno, por ejemplo "5 de 7 días con registro".<br>5. El paciente elige un periodo y "Descargar PDF".<br>6. El sistema genera el PDF con sus indicadores y su evolución, sus registros de cada día y el plan alimenticio de ese periodo.<br>7. El sistema guarda el PDF en la carpeta de descargas del teléfono y muestra "Tu informe está listo" con el nombre y el tamaño del archivo.<br>8. El paciente elige "Volver a mi progreso". |
| **Flujos alternos** | **5a. El periodo elegido no tiene ningún registro (RF-026):**<br>5a1. El sistema avisa que no hay información para ese periodo y no genera el PDF.<br>5a2. El caso regresa al paso 4.<br><br>**5b. El periodo elegido tiene más de 30 días de antigüedad (RF-027):**<br>5b1. El sistema genera el informe con el resumen mensual de ese mes, porque sus registros diarios ya fueron sustituidos.<br>5b2. El caso continúa en el paso 7.<br><br>**6a. Hay días sin registro en el periodo (RNF-CON-001):**<br>6a1. El informe muestra esos días como "Sin registro" y no los rellena.<br>6a2. El caso continúa en el paso 7.<br><br>**7a. El teléfono no tiene espacio para guardar el archivo (RF-026):**<br>7a1. El sistema avisa que no pudo guardar el informe y pide liberar espacio.<br>7a2. El paciente libera espacio en su teléfono.<br>7a3. El caso regresa al paso 5. |
| **Postcondición** | El paciente tiene el PDF de sus avances y su plan del periodo elegido. |
| **Requisitos que realiza** | RF-026, RF-027, RNF-CON-001 |
| **Pantallas del prototipo** | P05 Mi progreso, P06 Descargar informe, P06-A Informe descargado |
