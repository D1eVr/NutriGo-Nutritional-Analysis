# CU-20 · Desactivar una cuenta

| Campo | Contenido |
|---|---|
| **Actor principal** | Administrador |
| **Objetivo** | Impedir que un usuario siga entrando al sistema sin borrar su información. |
| **Precondición** | El administrador tiene la sesión iniciada. |
| **Escenario principal** | 1. El administrador abre la sección "Usuarios".<br>2. El administrador busca al usuario.<br>3. El administrador elige "Desactivar cuenta".<br>4. El sistema pide confirmar.<br>5. El administrador confirma.<br>6. El sistema desactiva la cuenta. |
| **Flujos alternos** | 5a. El administrador cancela: la cuenta sigue activa.<br>6a. La cuenta es de un nutriólogo: sus horarios dejan de mostrarse y sus citas pendientes o confirmadas aparecen como "Cancelada" para los pacientes. |
| **Postcondición** | El usuario ya no puede iniciar sesión y su información se conserva. |
| **Requisitos que realiza** | RF-029, RNF-SEG-003 |
