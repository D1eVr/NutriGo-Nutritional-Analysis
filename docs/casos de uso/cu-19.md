# CU-19 · Dar de alta a un nutriólogo

| Campo | Contenido |
|---|---|
| **Actor principal** | Administrador |
| **Objetivo** | Habilitar a un nutriólogo para que pueda registrar sus horarios y atender pacientes. |
| **Precondición** | El administrador tiene la sesión iniciada. |
| **Escenario principal** | 1. El administrador abre la sección "Usuarios".<br>2. El administrador elige "Agregar nutriólogo".<br>3. El administrador captura el nombre y el correo electrónico del nutriólogo.<br>4. El sistema verifica que el correo no esté registrado.<br>5. El sistema crea la cuenta y envía al correo del nutriólogo un enlace para crear su contraseña. |
| **Flujos alternos** | 4a. El correo ya está registrado: el sistema avisa y no crea la cuenta. |
| **Postcondición** | La cuenta del nutriólogo existe y, al crear su contraseña, puede entrar con las funciones de su rol. |
| **Requisitos que realiza** | RF-028, RNF-SEG-003 |
