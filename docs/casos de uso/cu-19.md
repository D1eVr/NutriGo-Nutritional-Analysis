# CU-19 · Dar de alta a un nutriólogo

| Campo | Contenido |
|---|---|
| **Actor principal** | Administrador |
| **Objetivo** | Habilitar a un nutriólogo para que pueda registrar sus horarios y atender pacientes. |
| **Precondición** | El administrador tiene la sesión iniciada. |
| **Escenario principal** | 1. El administrador abre la sección "Usuarios" y elige "Agregar nutriólogo".<br>2. El sistema pide el nombre y el correo electrónico del nutriólogo, y aclara que le enviará un enlace para crear su contraseña.<br>3. El administrador captura los datos y elige "Dar de alta".<br>4. El sistema verifica que los datos estén completos y que el correo no esté registrado.<br>5. El sistema crea la cuenta con el rol de nutriólogo y envía a su correo un enlace para crear su contraseña.<br>6. El sistema indica que el nutriólogo ya es parte de NutriGo! y a qué correo se envió el enlace.<br>7. El administrador elige "Volver a usuarios" y el nutriólogo aparece en la lista con el estado "Activa". |
| **Flujos alternos** | **4a. Falta el nombre o el correo (RF-028):**<br>4a1. El sistema no crea la cuenta y señala el campo vacío.<br>4a2. El administrador captura el dato que falta y elige "Dar de alta".<br>4a3. El caso regresa al paso 4.<br><br>**4b. El correo ya está registrado (RF-028):**<br>4b1. El sistema no crea la cuenta y avisa que ese correo ya pertenece a una cuenta.<br>4b2. Si el administrador escribió mal el correo, lo corrige y el caso regresa al paso 4.<br>4b3. Si la persona ya tenía una cuenta, el caso termina sin crear una cuenta nueva, porque un correo solo puede pertenecer a una cuenta. |
| **Postcondición** | La cuenta del nutriólogo existe y, al crear su contraseña, puede entrar con las funciones de su rol. |
| **Requisitos que realiza** | RF-028, RNF-SEG-003 |
| **Pantallas del prototipo** | P15 Usuarios, P15-A Agregar nutriólogo, P15-B Nutriólogo dado de alta |
