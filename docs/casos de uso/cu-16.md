# CU-16 · Atender una solicitud de cita

| Campo | Contenido |
|---|---|
| **Actor principal** | Nutriólogo |
| **Objetivo** | Decidir qué solicitudes de cita atiende dentro de los horarios que registró. |
| **Precondición** | El nutriólogo tiene la sesión iniciada y registró sus horarios de atención. |
| **Escenario principal** | 1. El nutriólogo abre la sección "Solicitudes".<br>2. El sistema muestra las solicitudes pendientes con fecha, hora y motivo de consulta.<br>3. El nutriólogo elige una solicitud.<br>4. El nutriólogo acepta la solicitud.<br>5. El sistema marca la cita como "Confirmada" y el paciente la ve así. |
| **Flujos alternos** | 2a. No hay solicitudes pendientes: el sistema lo indica.<br>3a. El paciente canceló la solicitud: aparece como "Cancelada" y no se puede responder.<br>4a. El nutriólogo rechaza la solicitud: el sistema la marca como "Rechazada" y libera el espacio. |
| **Postcondición** | La solicitud queda confirmada o rechazada, y el paciente conoce la respuesta. |
| **Requisitos que realiza** | RF-022, RNF-SEG-003 |
