# CU-16 · Atender una solicitud de cita

| Campo | Contenido |
|---|---|
| **Actor principal** | Nutriólogo |
| **Objetivo** | Decidir qué solicitudes de cita atiende dentro de los horarios que registró. |
| **Precondición** | El nutriólogo tiene la sesión iniciada y registró sus horarios de atención. |
| **Escenario principal** | 1. El nutriólogo elige "Ver solicitudes" en su panel.<br>2. El sistema muestra las solicitudes pendientes con el paciente, la fecha, la hora, el motivo y si el paciente comparte su progreso.<br>3. El nutriólogo elige una solicitud.<br>4. El nutriólogo elige "Aceptar".<br>5. El sistema marca la cita como "Confirmada" para el nutriólogo y para el paciente.<br>6. El sistema envía al paciente una notificación con la respuesta.<br>7. El sistema indica que el paciente ya ve la cita como confirmada y el nutriólogo elige "Volver al inicio". |
| **Flujos alternos** | **2a. No hay solicitudes pendientes (RF-022):**<br>2a1. El sistema indica que no tiene solicitudes pendientes.<br>2a2. El caso termina sin cambios, porque no hay solicitudes que responder.<br><br>**3a. El paciente canceló la solicitud antes de que el nutriólogo respondiera (RF-021, RF-022):**<br>3a1. La solicitud aparece como "Cancelada" y no muestra las opciones "Aceptar" ni "Rechazar".<br>3a2. El caso regresa al paso 2 para que el nutriólogo elija otra solicitud.<br><br>**4a. El nutriólogo rechaza la solicitud (RF-022):**<br>4a1. El nutriólogo elige "Rechazar".<br>4a2. El sistema marca la solicitud como "Rechazada", libera el espacio e indica que el horario quedó disponible para otros pacientes.<br>4a3. El caso continúa en el paso 6.<br><br>**6a. El paciente tiene desactivadas las notificaciones (RF-033):**<br>6a1. El sistema no puede mostrarle la notificación, pero la respuesta aparece igual en "Mis citas".<br>6a2. El caso continúa en el paso 7. |
| **Postcondición** | La solicitud queda confirmada o rechazada, y el paciente conoce la respuesta. |
| **Requisitos que realiza** | RF-022, RF-033, RNF-SEG-003 |
| **Pantallas del prototipo** | P11 Panel del nutriólogo, P12 Solicitudes de cita, P12-A Solicitud aceptada, P12-B Solicitud rechazada |
