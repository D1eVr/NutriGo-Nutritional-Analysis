# CU-02 · Iniciar sesión

| Campo | Contenido |
|---|---|
| **Actor principal** | Paciente, Nutriólogo o Administrador |
| **Objetivo** | Entrar a su cuenta para usar las funciones que corresponden a su rol. |
| **Precondición** | El usuario tiene la aplicación instalada en su teléfono y no ha iniciado sesión. |
| **Escenario principal** | 1. El usuario abre la aplicación y elige "Inicia sesión".<br>2. El sistema pide correo electrónico y contraseña.<br>3. El usuario escribe sus datos y elige "Iniciar sesión".<br>4. El sistema verifica que el correo pertenezca a una cuenta activa y que la contraseña corresponda.<br>5. El sistema abre la sesión y muestra la pantalla de inicio de su rol: el panel principal al paciente, el panel del nutriólogo al nutriólogo o la sección "Usuarios" al administrador. |
| **Flujos alternos** | **4a. El correo no está registrado o la contraseña no corresponde (RF-003):**<br>4a1. El sistema no da acceso y muestra "El correo o la contraseña no son correctos", sin indicar cuál de los dos datos falló.<br>4a2. El sistema ofrece "Intentar de nuevo", "¿Olvidaste tu contraseña?" y "Crear cuenta".<br>4a3. El usuario elige "Intentar de nuevo", corrige sus datos y el caso regresa al paso 3.<br><br>**4b. El usuario olvidó su contraseña (RF-004):**<br>4b1. En el paso 2 o en el paso 4a2, el usuario elige "¿Olvidaste tu contraseña?".<br>4b2. El sistema pide el correo electrónico de la cuenta.<br>4b3. El usuario escribe su correo y elige "Enviar enlace".<br>4b4. El sistema envía al correo un enlace para crear una nueva contraseña y muestra "Revisa tu correo".<br>4b5. El usuario abre el enlace y crea su nueva contraseña.<br>4b6. El usuario elige "Volver a iniciar sesión" y el caso regresa al paso 2.<br><br>**4c. La persona todavía no tiene cuenta (RF-001):**<br>4c1. En el paso 2 o en el paso 4a2, la persona elige "Crear cuenta".<br>4c2. La persona crea su cuenta siguiendo CU-01.<br>4c3. Como CU-01 deja la sesión iniciada, el caso continúa en el paso 5.<br><br>**4d. La cuenta está desactivada (RF-003, RF-029):**<br>4d1. El sistema no da acceso y le indica que su cuenta está desactivada.<br>4d2. El caso termina sin abrir la sesión, porque una cuenta desactivada no puede usarse para entrar (RNF-SEG-001). |
| **Postcondición** | El usuario tiene la sesión iniciada y solo ve las funciones de su rol. |
| **Requisitos que realiza** | RF-002, RF-003, RF-004, RNF-SEG-001, RNF-SEG-003 |
| **Relaciones** | Es extendido por CU-01 Crear una cuenta en el punto de extensión "sin cuenta" (flujo 4c). Lo usan los tres actores: Paciente, Nutriólogo y Administrador. |
| **Pantallas del prototipo** | P01 Inicio de sesión, P01-E1 Datos de acceso incorrectos, P01-B Recuperar contraseña, P01-C Revisa tu correo, P02 Panel principal, P11 Panel del nutriólogo, P15 Usuarios |
