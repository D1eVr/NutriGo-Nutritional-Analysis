# CU-02 · Iniciar sesión

| Campo | Contenido |
|---|---|
| **Actor principal** | Paciente, Nutriólogo o Administrador |
| **Objetivo** | Entrar a su cuenta para usar las funciones que corresponden a su rol. |
| **Precondición** | El usuario tiene la aplicación instalada en su teléfono. |
| **Escenario principal** | 1. El usuario abre la aplicación y elige "Iniciar sesión".<br>2. El sistema pide correo electrónico y contraseña.<br>3. El usuario los ingresa.<br>4. El sistema verifica que el correo pertenezca a una cuenta activa y que la contraseña corresponda.<br>5. El sistema abre la sesión y muestra la pantalla de inicio de su rol. |
| **Flujos alternos** | 4a. El correo no está registrado: el sistema no da acceso y ofrece crear una cuenta.<br>4b. La contraseña es incorrecta: el sistema no da acceso, avisa y deja intentar de nuevo.<br>4c. El usuario olvidó su contraseña: el sistema envía a su correo un enlace para crear una nueva y el caso regresa al paso 2.<br>4d. La cuenta está desactivada: el sistema no da acceso y se lo indica. |
| **Postcondición** | El usuario tiene la sesión iniciada y solo ve las funciones de su rol. |
| **Requisitos que realiza** | RF-002, RF-003, RF-004, RNF-SEG-001, RNF-SEG-003 |
