# CU-06 · Desvincular un dispositivo

| Campo | Contenido |
|---|---|
| **Actor principal** | Paciente |
| **Objetivo** | Dejar de recibir datos de un dispositivo que ya no usa. |
| **Precondición** | El paciente tiene la sesión iniciada y al menos un dispositivo vinculado. |
| **Escenario principal** | 1. El paciente abre la sección "Dispositivos".<br>2. El paciente elige el dispositivo y selecciona "Desvincular".<br>3. El sistema pide confirmar y aclara que los datos que ya se obtuvieron se conservan.<br>4. El paciente confirma.<br>5. El sistema desvincula el dispositivo y lo quita de la lista. |
| **Flujos alternos** | 4a. El paciente cancela: el dispositivo sigue vinculado. |
| **Postcondición** | El sistema ya no recibe datos de ese dispositivo y el historial del paciente se conserva completo. |
| **Requisitos que realiza** | RF-013 |
