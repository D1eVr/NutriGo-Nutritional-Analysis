# CU-06 · Desvincular un dispositivo

| Campo | Contenido |
|---|---|
| **Actor principal** | Paciente |
| **Objetivo** | Dejar de recibir datos de un dispositivo que ya no usa. |
| **Precondición** | El paciente tiene la sesión iniciada y al menos un dispositivo vinculado. |
| **Escenario principal** | 1. El paciente abre "Mis dispositivos".<br>2. El sistema muestra sus dispositivos vinculados con su estado y su última sincronización.<br>3. El paciente elige el dispositivo y selecciona "Desvincular".<br>4. El sistema pide confirmar y aclara que los datos que ya se obtuvieron se conservan en su historial.<br>5. El paciente confirma.<br>6. El sistema desvincula el dispositivo, lo quita de la lista e indica que el historial se conserva. |
| **Flujos alternos** | **5a. El paciente elige "Cancelar" (RF-013):**<br>5a1. El sistema cierra la confirmación y el dispositivo sigue vinculado.<br>5a2. El caso regresa al paso 2.<br><br>**6a. Era el único dispositivo vinculado (RF-013):**<br>6a1. El sistema muestra la lista sin dispositivos y la opción "Vincular un dispositivo".<br>6a2. Los datos que medía ese dispositivo pasan a la sección "Por registrar" del registro del día para capturarse a mano (RF-008).<br>6a3. El caso termina en el paso 6 con el dispositivo desvinculado. |
| **Postcondición** | El sistema ya no recibe datos de ese dispositivo y el historial del paciente se conserva completo. |
| **Requisitos que realiza** | RF-013 |
| **Pantallas del prototipo** | P08 Mis dispositivos, P08-C Desvincular dispositivo, P08-D Dispositivo desvinculado |
