# CU-14 · Solicitar una cita remota

| Campo | Contenido |
|---|---|
| **Actor principal** | Paciente |
| **Objetivo** | Obtener una cita remota con un nutriólogo en un horario en que pueda atenderlo. |
| **Precondición** | El paciente tiene la sesión iniciada. |
| **Escenario principal** | 1. El paciente elige "Consultas" en el menú inferior.<br>2. El sistema muestra los espacios disponibles de los nutriólogos para las próximas dos semanas, agrupados por nutriólogo y por día.<br>3. El paciente elige un espacio y "Solicitar cita".<br>4. El sistema muestra la fecha, la hora y el nutriólogo, y pide el motivo de la consulta.<br>5. El paciente escribe el motivo y activa la opción "Compartir mi progreso" para autorizar al nutriólogo.<br>6. El paciente elige "Enviar solicitud".<br>7. El sistema verifica que el motivo no esté vacío y que el espacio siga disponible.<br>8. El sistema registra la solicitud como "Pendiente", aparta el espacio y la muestra en "Mis citas" con el aviso de que recibirá una notificación cuando el nutriólogo responda. |
| **Flujos alternos** | **2a. No hay espacios disponibles en las próximas dos semanas (RF-019):**<br>2a1. El sistema indica que no hay horarios disponibles.<br>2a2. El caso termina sin registrar una solicitud; el paciente puede volver a consultar los horarios más tarde.<br><br>**5a. El paciente no activa "Compartir mi progreso" (RF-023):**<br>5a1. La solicitud se registrará igual, pero el nutriólogo no podrá ver su información.<br>5a2. El caso continúa en el paso 6.<br><br>**7a. El motivo está vacío (RF-020):**<br>7a1. El sistema no envía la solicitud y señala el campo del motivo.<br>7a2. El paciente escribe el motivo.<br>7a3. El caso regresa al paso 6.<br><br>**7b. Otro paciente tomó el espacio mientras tanto (RF-020):**<br>7b1. El sistema no registra la solicitud y avisa que el horario ya no está disponible.<br>7b2. El caso regresa al paso 2, donde el espacio ya no aparece. |
| **Postcondición** | La solicitud queda pendiente para el paciente y para el nutriólogo, y el espacio deja de estar disponible. Si el paciente compartió su progreso, el nutriólogo puede consultarlo. |
| **Requisitos que realiza** | RF-019, RF-020, RF-023, RF-033, RNF-SEG-002 |
| **Pantallas del prototipo** | P10 Consultas, P10-A Solicitar cita, P10-B Mis citas |
