# CU-14 · Solicitar una cita remota

| Campo | Contenido |
|---|---|
| **Actor principal** | Paciente |
| **Objetivo** | Obtener una cita remota con un nutriólogo en un horario en que pueda atenderlo. |
| **Precondición** | El paciente tiene la sesión iniciada. |
| **Escenario principal** | 1. El paciente abre la sección "Consultas".<br>2. El sistema muestra los espacios disponibles de los nutriólogos para las próximas dos semanas.<br>3. El paciente elige un espacio.<br>4. El paciente escribe el motivo de la consulta y elige si autoriza al nutriólogo a ver su progreso.<br>5. El paciente confirma la solicitud.<br>6. El sistema registra la solicitud como "Pendiente" y aparta ese espacio. |
| **Flujos alternos** | 2a. No hay espacios disponibles: el sistema lo indica.<br>4a. El paciente no autoriza al nutriólogo: la solicitud se registra igual, pero el nutriólogo no ve su información.<br>5a. Otro paciente tomó el espacio mientras tanto: el sistema avisa y el caso regresa al paso 2. |
| **Postcondición** | La solicitud queda pendiente para el paciente y para el nutriólogo, y el espacio deja de estar disponible. |
| **Requisitos que realiza** | RF-019, RF-020, RF-023, RNF-SEG-002 |
