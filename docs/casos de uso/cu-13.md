# CU-13 · Registrar los horarios de atención

| Campo | Contenido |
|---|---|
| **Actor principal** | Nutriólogo |
| **Objetivo** | Indicar en qué días y horas puede atender a sus pacientes para que solo le soliciten citas en esos horarios. |
| **Precondición** | El nutriólogo tiene la sesión iniciada. |
| **Escenario principal** | 1. El nutriólogo elige "Ver horarios" en su panel.<br>2. El sistema muestra los días de la semana con su horario o con "Sin horario", y la duración de cada cita.<br>3. El nutriólogo elige los días, la hora de inicio, la hora de fin y la duración de cada cita.<br>4. El sistema calcula e indica cuántos espacios verán los pacientes en cada día, por ejemplo "Los pacientes verán 4 espacios cada martes".<br>5. El nutriólogo elige "Guardar horarios".<br>6. El sistema guarda los horarios y muestra a los pacientes los espacios disponibles de las próximas dos semanas. |
| **Flujos alternos** | **5a. La hora de fin es igual o anterior a la hora de inicio (RF-018):**<br>5a1. El sistema no guarda el horario y señala el día con el error.<br>5a2. El nutriólogo corrige la hora.<br>5a3. El caso regresa al paso 4.<br><br>**5b. El nutriólogo modifica un horario que ya tiene citas pendientes o confirmadas (RF-018):**<br>5b1. El sistema avisa cuántas citas hay en ese horario y que se conservarán.<br>5b2. El sistema guarda el horario nuevo sin cancelar esas citas.<br>5b3. El caso continúa en el paso 6. |
| **Postcondición** | Los pacientes ven los espacios disponibles del nutriólogo para las próximas dos semanas. |
| **Requisitos que realiza** | RF-018, RNF-SEG-003 |
| **Pantallas del prototipo** | P11 Panel del nutriólogo, P14 Mis horarios |
