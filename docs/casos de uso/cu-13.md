# CU-13 · Registrar los horarios de atención

| Campo | Contenido |
|---|---|
| **Actor principal** | Nutriólogo |
| **Objetivo** | Indicar en qué días y horas puede atender a sus pacientes para que solo le soliciten citas en esos horarios. |
| **Precondición** | El nutriólogo tiene la sesión iniciada. |
| **Escenario principal** | 1. El nutriólogo abre la sección "Mis horarios".<br>2. El nutriólogo elige los días de la semana, la hora de inicio, la hora de fin y la duración de cada cita.<br>3. El nutriólogo guarda sus horarios.<br>4. El sistema genera los espacios de cita y los muestra disponibles para los pacientes. |
| **Flujos alternos** | 3a. La hora de fin es anterior a la hora de inicio: el sistema no guarda el horario y señala el error.<br>3b. El nutriólogo modifica un horario que ya tiene citas confirmadas: el sistema conserva esas citas. |
| **Postcondición** | Los pacientes ven los espacios disponibles del nutriólogo para las próximas dos semanas. |
| **Requisitos que realiza** | RF-018, RNF-SEG-003 |
