# CU-15 · Cancelar una cita

| Campo | Contenido |
|---|---|
| **Actor principal** | Paciente |
| **Objetivo** | Cancelar una cita a la que ya no puede asistir para liberar el horario. |
| **Precondición** | El paciente tiene la sesión iniciada y una cita pendiente o confirmada. |
| **Escenario principal** | 1. El paciente abre "Consultas" y elige "Mis citas".<br>2. El sistema muestra sus citas con la fecha, la hora, el nutriólogo, el motivo y el estado.<br>3. El paciente elige la cita y selecciona "Cancelar cita".<br>4. El sistema pide confirmar la cancelación.<br>5. El paciente confirma.<br>6. El sistema marca la cita como "Cancelada" para el paciente y para el nutriólogo, libera el espacio e indica que el horario quedó disponible para otros pacientes.<br>7. El paciente elige "Volver a consultas". |
| **Flujos alternos** | **3a. La cita elegida está "Rechazada" o "Cancelada" (RF-021):**<br>3a1. El sistema no muestra la opción "Cancelar cita".<br>3a2. El caso regresa al paso 2 para que el paciente elija otra cita.<br><br>**5a. El paciente no confirma la cancelación (RF-021):**<br>5a1. La cita se mantiene sin cambios.<br>5a2. El caso regresa al paso 2. |
| **Postcondición** | La cita aparece como cancelada y el espacio vuelve a estar disponible para otros pacientes. |
| **Requisitos que realiza** | RF-021 |
| **Pantallas del prototipo** | P10 Consultas, P10-B Mis citas, P10-C Cita cancelada |
