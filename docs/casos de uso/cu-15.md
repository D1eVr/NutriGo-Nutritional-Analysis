# CU-15 · Cancelar una cita

| Campo | Contenido |
|---|---|
| **Actor principal** | Paciente |
| **Objetivo** | Cancelar una cita a la que ya no puede asistir para liberar el horario. |
| **Precondición** | El paciente tiene la sesión iniciada y una cita pendiente o confirmada. |
| **Escenario principal** | 1. El paciente abre la sección "Mis citas".<br>2. El paciente elige la cita que quiere cancelar.<br>3. El paciente selecciona "Cancelar cita" y confirma.<br>4. El sistema marca la cita como "Cancelada" para el paciente y para el nutriólogo, y libera el espacio. |
| **Flujos alternos** | 3a. El paciente no confirma la cancelación: la cita se mantiene sin cambios. |
| **Postcondición** | La cita aparece como cancelada y el espacio vuelve a estar disponible para otros pacientes. |
| **Requisitos que realiza** | RF-021 |
