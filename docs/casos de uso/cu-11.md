# CU-11 · Configurar las preferencias alimenticias

| Campo | Contenido |
|---|---|
| **Actor principal** | Paciente |
| **Objetivo** | Indicar su objetivo, sus gustos y lo que no puede comer para que su plan alimenticio lo respete. |
| **Precondición** | El paciente tiene la sesión iniciada. |
| **Escenario principal** | 1. El paciente abre su perfil y elige "Preferencias alimenticias".<br>2. El sistema muestra su objetivo, sus alergias, sus restricciones y los alimentos que no le gustan.<br>3. El paciente elige su objetivo: bajar de peso, mantener su peso o ganar masa muscular.<br>4. El paciente agrega o quita alergias, restricciones y alimentos que no le gustan.<br>5. El paciente elige "Guardar preferencias".<br>6. El sistema verifica que haya un objetivo elegido.<br>7. El sistema guarda las preferencias e indica que los cambios se aplican en su siguiente plan. |
| **Flujos alternos** | **1a. Es la primera vez que el paciente abre su plan y no tiene preferencias (RF-016):**<br>1a1. El sistema lo lleva a esta sección antes de generar su primer plan.<br>1a2. El caso continúa en el paso 2.<br>1a3. Al terminar el paso 7, el sistema genera su primer plan y el paciente continúa en CU-12.<br><br>**4a. El paciente no tiene alergias ni restricciones (RF-015):**<br>4a1. El paciente deja vacías esas secciones.<br>4a2. El caso continúa en el paso 5.<br><br>**5a. El paciente sale sin guardar (RF-015):**<br>5a1. El sistema descarta los cambios y conserva las preferencias anteriores.<br>5a2. El caso regresa al paso 1, con el paciente en su perfil.<br><br>**6a. El paciente no eligió un objetivo (RF-015):**<br>6a1. El sistema no guarda y señala el campo "Mi objetivo".<br>6a2. El paciente elige su objetivo y "Guardar preferencias".<br>6a3. El caso regresa al paso 6. |
| **Postcondición** | Las preferencias alimenticias quedan guardadas y se usan para generar el siguiente plan. |
| **Requisitos que realiza** | RF-015 |
| **Relaciones** | «extend» hacia CU-12 Consultar el plan alimenticio semanal, en el punto de extensión "sin preferencias" (flujo 1a de CU-12). También puede iniciarse desde el perfil. |
| **Pantallas del prototipo** | P07 Perfil, P07-B Preferencias alimenticias |
