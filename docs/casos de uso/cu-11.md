# CU-11 · Configurar las preferencias alimenticias

| Campo | Contenido |
|---|---|
| **Actor principal** | Paciente |
| **Objetivo** | Indicar su objetivo, sus gustos y lo que no puede comer para que su plan alimenticio lo respete. |
| **Precondición** | El paciente tiene la sesión iniciada. |
| **Escenario principal** | 1. El paciente abre la sección "Preferencias alimenticias".<br>2. El sistema muestra su objetivo, sus preferencias, sus alergias, sus restricciones y los alimentos que no le gustan.<br>3. El paciente llena o modifica la información.<br>4. El paciente guarda los cambios.<br>5. El sistema guarda las preferencias e indica que se tomarán en cuenta en el siguiente plan. |
| **Flujos alternos** | 1a. Es la primera vez que el paciente abre su plan: el sistema lo lleva a esta sección antes de generar su primer plan.<br>3a. El paciente no tiene alergias: marca la opción "Sin alergias" y el caso continúa en el paso 4. |
| **Postcondición** | Las preferencias alimenticias quedan guardadas y se usan para generar el siguiente plan. |
| **Requisitos que realiza** | RF-015 |
