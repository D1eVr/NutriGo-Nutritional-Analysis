# CU-18 · Revisar el progreso de un paciente

| Campo | Contenido |
|---|---|
| **Actor principal** | Nutriólogo |
| **Objetivo** | Conocer la evolución de un paciente que lo autorizó para darle seguimiento. |
| **Precondición** | El nutriólogo tiene la sesión iniciada. |
| **Escenario principal** | 1. El nutriólogo abre la sección "Mis pacientes".<br>2. El sistema muestra la lista de pacientes que lo autorizaron.<br>3. El nutriólogo elige un paciente.<br>4. El sistema muestra sus indicadores, su gráfica de evolución y sus registros diarios, incluidos los días sin registro. |
| **Flujos alternos** | 2a. Ningún paciente lo ha autorizado: el sistema indica que no tiene pacientes en su lista.<br>3a. El paciente retiró su autorización: el sistema no abre su información y avisa al nutriólogo. |
| **Postcondición** | El nutriólogo conoce el progreso del paciente sin poder modificar sus datos. |
| **Requisitos que realiza** | RF-025, RNF-SEG-002, RNF-CON-001 |
