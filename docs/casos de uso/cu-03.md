# CU-03 · Cerrar sesión

| Campo | Contenido |
|---|---|
| **Actor principal** | Paciente, Nutriólogo o Administrador |
| **Objetivo** | Salir de su cuenta para que nadie más vea su información desde ese teléfono. |
| **Precondición** | El usuario tiene la sesión iniciada. |
| **Escenario principal** | 1. El usuario elige "Cerrar sesión": el paciente desde su perfil, el nutriólogo desde su panel y el administrador desde la sección "Usuarios".<br>2. El sistema pide confirmar.<br>3. El usuario confirma.<br>4. El sistema cierra la sesión y muestra la pantalla de inicio de sesión. |
| **Flujos alternos** | **3a. El usuario cancela (RF-005):**<br>3a1. El sistema mantiene la sesión abierta y regresa a la pantalla desde la que eligió "Cerrar sesión".<br>3a2. El caso regresa al paso 1, donde el usuario puede volver a elegir "Cerrar sesión" cuando lo decida.<br><br>**4a. Después de cerrar sesión, el usuario presiona "atrás" en su teléfono (RNF-SEG-001):**<br>4a1. El sistema permanece en la pantalla de inicio de sesión y no muestra ninguna información de la cuenta.<br>4a2. El caso termina en el paso 4 con la sesión cerrada. |
| **Postcondición** | La aplicación no muestra ninguna información hasta que el usuario vuelve a iniciar sesión. |
| **Requisitos que realiza** | RF-005, RNF-SEG-001 |
| **Relaciones** | Lo usan los tres actores: Paciente, Nutriólogo y Administrador. |
| **Pantallas del prototipo** | P07 Perfil, P11 Panel del nutriólogo, P15 Usuarios, P01 Inicio de sesión |
