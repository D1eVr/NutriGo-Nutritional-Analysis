# CU-03 · Cerrar sesión

| Campo | Contenido |
|---|---|
| **Actor principal** | Paciente, Nutriólogo o Administrador |
| **Objetivo** | Salir de su cuenta para que nadie más vea su información desde ese teléfono. |
| **Precondición** | El usuario tiene la sesión iniciada. |
| **Escenario principal** | 1. El usuario abre el menú de su cuenta y elige "Cerrar sesión".<br>2. El sistema pide confirmar.<br>3. El usuario confirma.<br>4. El sistema cierra la sesión y muestra la pantalla de inicio de sesión. |
| **Flujos alternos** | 3a. El usuario cancela: el sistema mantiene la sesión abierta y regresa a la pantalla anterior. |
| **Postcondición** | La aplicación no muestra ninguna información hasta que el usuario vuelve a iniciar sesión. |
| **Requisitos que realiza** | RF-005, RNF-SEG-001 |
