# CU-12 · Consultar el plan alimenticio semanal

| Campo | Contenido |
|---|---|
| **Actor principal** | Paciente |
| **Objetivo** | Saber qué comer cada día de la semana según un plan ajustado a sus preferencias y a sus resultados. |
| **Precondición** | El paciente tiene la sesión iniciada. |
| **Escenario principal** | 1. El paciente elige "Plan" en el menú inferior.<br>2. El sistema muestra la semana vigente de lunes a domingo, con el día actual seleccionado, y el aviso con el número de días que se usaron para ajustar el plan.<br>3. El sistema muestra las comidas del día seleccionado, organizadas en desayuno, colación, comida y cena.<br>4. El paciente elige otro día de la semana.<br>5. El sistema muestra las comidas de ese día. |
| **Flujos alternos** | **1a. El paciente no tiene preferencias alimenticias registradas (RF-016):**<br>1a1. El sistema le pide registrarlas antes de generar su primer plan.<br>1a2. El paciente registra sus preferencias como se describe en CU-11.<br>1a3. El sistema genera su primer plan con sus datos personales y sus preferencias.<br>1a4. El caso continúa en el paso 2.<br><br>**2a. Es el primer plan del paciente (RF-016):**<br>2a1. Como no existe una semana anterior, el aviso indica que el plan se generó con sus datos personales y sus preferencias.<br>2a2. El caso continúa en el paso 3.<br><br>**2b. Es lunes y comienza una semana nueva (RF-017):**<br>2b1. El sistema muestra el plan nuevo, generado con los registros de la semana anterior, que reemplaza al de esa semana.<br>2b2. El aviso indica cuántos días de la semana anterior tenían registro, por ejemplo "Ajustamos tu plan con los 5 días que registraste la semana pasada".<br>2b3. El caso continúa en el paso 3.<br><br>**5a. El paciente quiere revisar otro día (RF-030):**<br>5a1. Después de ver las comidas del día elegido, el paciente quiere consultar un día distinto.<br>5a2. El caso regresa al paso 4. |
| **Postcondición** | El paciente conoce las comidas de cada día de su plan vigente. |
| **Requisitos que realiza** | RF-016, RF-017, RF-030 |
| **Relaciones** | Es extendido por CU-11 Configurar las preferencias alimenticias en el punto de extensión "sin preferencias" (flujo 1a). |
| **Pantallas del prototipo** | P02 Panel principal (tarjeta Tu plan de hoy), P09 Plan semanal |
