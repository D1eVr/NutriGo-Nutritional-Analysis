# CU-12 · Consultar el plan alimenticio semanal

| Campo | Contenido |
|---|---|
| **Actor principal** | Paciente |
| **Objetivo** | Saber qué comer cada día de la semana según un plan ajustado a sus preferencias y a sus resultados. |
| **Precondición** | El paciente tiene la sesión iniciada. |
| **Escenario principal** | 1. El paciente abre la sección "Plan alimenticio".<br>2. El sistema muestra las comidas del día actual organizadas por tiempo de comida.<br>3. El paciente elige otro día de la semana.<br>4. El sistema muestra las comidas de ese día. |
| **Flujos alternos** | 1a. El paciente no tiene preferencias alimenticias registradas: el sistema le pide registrarlas antes de generar su primer plan.<br>2a. Es lunes: el sistema muestra el plan nuevo generado con los registros de la semana anterior e indica cuántos días tenían registro. |
| **Postcondición** | El paciente conoce las comidas de cada día de su plan vigente. |
| **Requisitos que realiza** | RF-016, RF-017 |
