# CU-05 · Vincular un dispositivo

| Campo | Contenido |
|---|---|
| **Actor principal** | Paciente |
| **Objetivo** | Conectar su reloj, banda de actividad o báscula inteligente para que sus datos se registren solos. |
| **Precondición** | El paciente tiene la sesión iniciada y su dispositivo está encendido y configurado. |
| **Escenario principal** | 1. El paciente abre la sección "Dispositivos" y elige "Vincular dispositivo".<br>2. El sistema muestra los tipos de dispositivo compatibles: reloj, banda de actividad y báscula.<br>3. El paciente elige su dispositivo y autoriza que NutriGo! reciba sus datos.<br>4. El sistema verifica que el dispositivo sea compatible.<br>5. El sistema vincula el dispositivo y lo muestra como conectado, con la fecha y hora de su última sincronización. |
| **Flujos alternos** | 3a. El paciente no autoriza el acceso a sus datos: el sistema no vincula el dispositivo y regresa a la lista.<br>4a. El dispositivo no es compatible: el sistema avisa y el paciente sigue registrando sus datos a mano. |
| **Postcondición** | El dispositivo queda vinculado y sus mediciones empiezan a aparecer en el registro diario. |
| **Requisitos que realiza** | RF-011 |
