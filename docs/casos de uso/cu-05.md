# CU-05 · Vincular un dispositivo

| Campo | Contenido |
|---|---|
| **Actor principal** | Paciente |
| **Objetivo** | Conectar su reloj, banda de actividad o báscula inteligente para que sus datos se registren solos. |
| **Precondición** | El paciente tiene la sesión iniciada y su dispositivo está encendido y configurado en la aplicación de su fabricante. |
| **Escenario principal** | 1. El paciente abre "Mis dispositivos" desde su perfil o desde el panel principal y elige "Vincular un dispositivo".<br>2. El sistema muestra los tipos de dispositivo compatibles y los datos que mide cada uno: reloj inteligente y banda de actividad (sueño y actividad física), báscula inteligente (peso, grasa y masa muscular) y otro dispositivo compatible.<br>3. El paciente elige su dispositivo y elige "Autorizar y vincular".<br>4. El sistema verifica que el dispositivo sea compatible y que el paciente haya autorizado el acceso a sus datos.<br>5. El sistema vincula el dispositivo y lo muestra en "Mis dispositivos" como conectado, con la fecha y hora de su última sincronización.<br>6. El paciente elige "Listo" y el sistema regresa a "Mis dispositivos". |
| **Flujos alternos** | **4a. El paciente no autoriza el acceso a sus datos (RF-011):**<br>4a1. El sistema no vincula el dispositivo y avisa que necesita la autorización para recibir sus datos.<br>4a2. El caso regresa al paso 2.<br><br>**4b. El dispositivo no es compatible (RF-011):**<br>4b1. El sistema no vincula el dispositivo y avisa que ese modelo no es compatible.<br>4b2. Si el paciente tiene otro dispositivo, el caso regresa al paso 2 para que lo elija.<br>4b3. Si no tiene otro dispositivo compatible, el caso termina sin vincular y el paciente sigue capturando sus datos a mano en el registro del día (RF-008).<br><br>**4c. El dispositivo no responde porque está apagado o sin conexión (RF-011):**<br>4c1. El sistema avisa que no pudo conectarse y pide revisar que el dispositivo esté encendido y configurado.<br>4c2. El paciente revisa su dispositivo y elige de nuevo "Autorizar y vincular".<br>4c3. El caso regresa al paso 4.<br><br>**5a. El dispositivo ya estaba vinculado (RF-011):**<br>5a1. El sistema no lo vincula dos veces e indica que ya está conectado, con su última sincronización.<br>5a2. El caso continúa en el paso 6. |
| **Postcondición** | El dispositivo queda vinculado y sus mediciones empiezan a aparecer en el registro diario. |
| **Requisitos que realiza** | RF-011 |
| **Pantallas del prototipo** | P07 Perfil, P08 Mis dispositivos, P08-A Vincular un dispositivo, P08-B Dispositivo vinculado |
